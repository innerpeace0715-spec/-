# EBSi 모의고사 아이패드 자동 받기

구성: **북마클릿**(사파리에서 링크 수집) + **단축어**(링크 목록을 파일 앱 폴더에 한 번에 저장)

## 1. 북마클릿 설치 (한 번만)
1. `bookmarklet.txt` 내용 전체를 복사합니다 (`javascript:`로 시작).
2. 사파리에서 아무 페이지나 연 뒤, 공유 → 북마크 추가 → 이름을 `EBSi받기`로 하고 저장합니다.
3. 북마크 목록에서 `EBSi받기`를 길게 누르고 편집을 고른 뒤, 주소 칸을 지우고 복사한 코드를 붙여넣습니다.

## 2. 단축어 만들기 (한 번만)
단축어 앱에서 + 를 누르고 아래 동작을 순서대로 추가합니다.
1. **클립보드 가져오기**
2. **텍스트 분할**: 구분자를 `새로운 줄`로 설정
3. **각 항목 반복**
   - **URL의 콘텐츠 가져오기**: 입력을 `반복 항목`으로 설정
   - **파일 저장**: `저장 위치 묻기`를 끄고 폴더를 지정(예: 파일 > iCloud Drive > EBSi), `덮어쓰기`는 끔
4. 이름을 `EBSi저장`으로 지정합니다.

## 3. 사용
1. 사파리에서 EBSi에 로그인하고 기출문제 페이지로 가서 필터를 맞춥니다.
2. 북마크에서 `EBSi받기`를 누르면 이 페이지의 파일 목록 패널이 뜹니다.
3. 다음 페이지로 넘기고 다시 `EBSi받기`를 누릅니다. 페이지마다 이렇게 하면 링크가 누적됩니다.
4. **누적 링크 전부 복사** → 단축어 `EBSi저장` 실행 → 파일 앱에 전부 저장됩니다.
5. 다 받았으면 **누적 비우기**를 누릅니다.

- 단축어로 받은 파일이 열리지 않으면(로그인이 필요한 파일이라면) 패널의 링크를 하나씩 눌러 공유 → 파일에 저장으로 받으면 됩니다.
- "링크를 못 찾음"이 뜨면 그 화면을 캡처해서 보내주세요.
